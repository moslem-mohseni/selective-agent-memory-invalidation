# Full-text positioning notes

Date: 2026-10-26. Versions are pinned below. These are literature readings, not replications; no external benchmark was run.

## MemGuard - Wang et al. (2026), arXiv:2608.21867v1
- Full text: https://arxiv.org/html/2608.21867v1
- The method attaches persistent verification descriptors to experience records.
- Descriptors govern later retrieval and retirement, rather than only initial admission.
- Evaluation compares complete memory systems on terminal, software and web tasks.
- Limitations discuss verifier errors and stale interface hints explicitly.
- Overlap: verification and stale-memory governance are established ideas.
- Distinction: P1 isolates an imposed external contract diff and maintenance coverage.
- P1 neither implements MemGuard nor inherits its real-agent performance evidence.

## MACE - Yang et al. (2026), arXiv:2609.21533v1
- Full text: https://arxiv.org/html/2609.21533v1
- Functional memory units group conditions, actions and outputs with typed relations.
- Composition and agent-specific presentation adapt using execution feedback.
- Controlled experiments include dependency retention and noisy retrieval.
- The paper distinguishes locally controlled comparisons from imported auxiliary baselines.
- Overlap: preserving dependency structure is already a measured design concern.
- Distinction: P1 measures contract-change invalidation using an exact executable ledger.
- Its simple trace grammar is substantially narrower than MACE's memory graphs.

## More Memory, Worse Agents - Wang et al. (2026), arXiv:2610.27406v1
- Full text: https://arxiv.org/html/2610.27406v1
- Anti-Persistence retains trajectories while reconstructing temporary guidance.
- It distinguishes direct error reuse from reproduction through descendant abstractions.
- Main evaluation freezes memory during held-out task evaluation.
- Appendix F.2 already tests selective filtering and a frozen persistent skill layer.
- That overlap removes any defensible claim that selective retention itself is new.
- P1 instead isolates an external contract change and measures probe/relearning trade-offs.
- P1 has no abstraction genealogy and cannot claim to reproduce error reproduction.

## Positioning decision
The revised manuscript claims a controlled measurement contribution. Dependency-directed revision, persistent verification evidence, linked memory and selective retention are acknowledged predecessors. The toy executable grammar and unavailable real-model validation constrain transfer claims.

The Anti-Persistence full-text limitations further restrict interpretation of its descendant audit: reported associations are descriptive and do not establish a causal reproduction effect. P1 does not reuse those aggregates or their uncertainty estimates.
